# About

I create documentation for enterprise products with complex processes, including APIs, SDKs, identity and security services, and fintech software. My work spans user guides, API references, tutorials, release notes, standards, and training.

In my current role, I create internal training, user documentation, and specifications for equities and options exchange markets.

## Experience

My recent experience includes the following roles:

- **Amazon Web Services:** Technical writer for AWS Identity services, including IAM, AWS STS, AWS Sign-in, AWS Builder ID, and IAM Identity Center. I wrote user guides, API references, tutorials, and troubleshooting content, and led cross-service content strategy for feature launches.
- **Finastra:** Senior technical writer and team lead for retail core banking software. I established a cloud help platform, drove adoption of Agile documentation processes, and trained writers on API documentation standards and authoring tools.

## How I work

My approach to documentation focuses on the following practices:

- Organizing content around the tasks readers need to complete, using a Jobs to Be Done approach
- Using customer feedback, support tickets, and usage metrics to find and prioritize documentation gaps
- Verifying content with subject matter experts and against the product before publishing
- Using AI tools to speed up repetitive work, and checking every result against the source
