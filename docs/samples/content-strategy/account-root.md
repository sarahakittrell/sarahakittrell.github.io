# Centrally manage root access

This sample is the documentation for a complete AWS feature, covering the account root and the Centrally manage root access feature across AWS services.

## About this sample

The project details are as follows:

- **Audience:** AWS account owners and administrators who manage organizations
- **Problem:** The new Centrally manage root access feature reduced how often users need to sign in as root, so the documentation needed to cover the feature and narrow the existing content to the tasks that still require root
- **My role:** Wrote the documentation for the new feature, and rewrote the existing account root content to be easier to understand
- **Collaborators:** Writers and product managers for AWS Organizations, AWS Sign-in, Amazon S3, and Amazon SQS
- **Verification:** Worked closely with developers and product managers to confirm that the documentation captured the purpose of the feature
- **Outcome:** Led the cross-service content strategy for the launch, which resulted in a synchronized documentation release across the impacted services

## View the documentation

The full feature documentation is available as a single PDF, and the current version is published in the IAM User Guide:

- **Other account root topics:** Major rewrite of the existing content to make it easier to use
