# Reporting feature release note

This sample is an in-depth release note for a new cloud-based reporting feature in core banking software.

## About this sample

The project details are as follows:

- **Audience:** Financial institution staff who create and share reports
- **Problem:** Customers needed to understand the new feature and how it differed from the existing reporting solution
- **My role:** Wrote the release note as sole author
- **Collaborators:** Developers and product managers
- **Verification:** Tested the feature in sandbox while drafting, and then reviewed the release note with the developers who designed it
- **Outcome:** Gave customers the information they needed to choose between the two reporting solutions before licensing the new feature

## Excerpt

The following excerpt introduces the feature and compares it with the existing reporting module, so customers can choose the right solution. Product and module names have been replaced with generic names.

!!! note
    The new reporting feature is a separately licensed enhancement that requires setup by the vendor. Contact your account executive for more information.

The new reporting feature uses Microsoft Power BI, a business analytics service, to provide interactive visualization and business intelligence with a simple interface for creating reports and dashboards. The feature provides the following improvements over the existing reporting module:

- Analyze customer and member data in real time, and embed the results in customer journeys to fulfill transaction requests and service queries quickly.
- Create, publish, view, and share reports with easy-to-use tools.
- Use rich visualizations and built-in data models.
- Run reports in the cloud, without an on-premises installation.
- Tailor dashboard views to the needs of executive management.

### Choosing a reporting solution

The core banking platform provides two reporting and analytics solutions. Both let you create reports and analyze system data without SQL skills or database training, and both let you join fields across the database to build custom reports.

**Existing reporting module:** Outputs data to tabular, matrix, and chart reports. This solution requires an on-premises installation on a SQL server. You can create and share reports in a variety of formats, but you can't visualize the underlying core data. This module is the best choice for paginated reports, which typically include long lists of data.

**New reporting feature:** Provides a similar ability to create and share reports, using a cloud-based analytics tool. In addition to lists of data, you can interact with your data through the Power BI service, using visualizations to drill down into report data. Reports refresh in real time against the database defined for the report. This solution isn't recommended for paginated reports or archiving past data. To get paginated data, export a report to Microsoft Excel.

!!! important
    You can't migrate reports from the existing reporting module to the new reporting feature.
