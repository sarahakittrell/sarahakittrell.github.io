Mail Agent Integration

When a customer/member sends a text message to a Long Code, the system sends an email notification to all employees assigned to the Long Code. In order for an employee to get an email alert that a text message has been received, the employee must:

be mapped to the Long Code that receives a text (Employee Long Code Mapping window).

have a valid work email address entered on their employee record (Add New/Edit Existing Employee window > Admin & Security tab).

When a text message is sent to the Long Code, an email is sent the next time the Mail Agent service polls the GB_EMAIL table. 

Note: The polling interval is defined on the Email tab of the Institution Controls window in System Administration. Go to the Mail Agent Installation Guide included with the Mail Agent installer files to review setup details.

Sample Email

Subject: Text Message Received

Message Body: You have received a text message from [phone number], go to Customer/Member Management to view the details.
