Customer/Member Management SMS Interface Overview

Reading and sending text messages is performed on the Text Message window in Customer/Member Management. The window updates automatically when a new text message is received from the customer/member. Clicking on a message changes the highlight color of the text message.

Note: All employees mapped to a Long Code can read text messages sent and received from the Long Code. Also, messages sent by different employees using the same Long Code appear as if all texts are sent from the same account.

Text Message Consent

Customers/Members receive their first text with a message that they can reply STOP to remove consent for receiving SMS texts. When STOP in sent in reply to any text, the Consent field is updated to Y (Valid, Voice Only) for the customer/member’s mobile number that received the text.

You can send and receive text messages on mobile numbers with the following consent settings on the Address & Contact Information tab of the Add New/Edit Existing Customer/Member window:

Mobile: Selected (Yes) 

Consent: 

B (SMS Text & Voice)

G (Portability Agreed)

H (Portability Not Agreed)

S (Valid, SMS Contact Only)

U (Unlisted)

V (Valid, Voice Only)

SMS Messaging Activity

All text history is displayed in the Text Message window in Customer/Member Management. You can also search for previous messages on the Customer/Member Contact History window. 

Note: After STOP is received, previous messages can only be viewed from the Customer/Member Contact History window.

Select the Contact Type filter and choose Text Message to show only SMS messaging activity.

Description indicates whether the text was sent or received.
