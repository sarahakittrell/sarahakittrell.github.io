Add Employees Window

Window Path: System Administration > Institution button on the ribbon > Interfaces button > SMS Service option > Edit button > Lng Cd Map button  > New/Edit button > Close button > Add button

This window allows you to add one or more employees to map the user to the long code. This allows the selected employees to send text messages from a digital phone number through Customer/Member Management.

Note: Text Messaging integration is a separately licensed enhancement that requires setup by Professional Services. Please contact your Account Executive for more information.

Table

Employee ID

This column displays the unique number that identifies an employee.

Employee Name

This column displays the full name of the employee.

Status

This column displays the status of the employee record.

Action

Select

This button assigns the selected employee(s) to a digital phone number (long code), so they can send text messages to customers/members. Selected employees are displayed on the Employee Long Code Mapping window.

Note: Press SHIFT or CTRL to select multiple employees.
