Text Message Window

 

Window Path: Customer/Member Management > Contact icon on the ribbon > Text Customer/Member option

This window displays the text message thread and allows the employee to send text messages to the customer/member phone number.

Notes:

This window can also be displayed from the Relationship Management window when the customer/member phone number link is clicked. The phone number must be a mobile number that the customer/member has consented to be contacted through SMS message.

Text Messaging interface is a separately licensed enhancement that requires setup by Professional Services. Contact your Account Executive for more information.

Text Communication

Customer/Member

This field displays the name of the customer/member being messaged.

Customer/Member SMS Number

This field displays the customer/member phone number being texted.

Institution SMS Number

This field displays the text messaging service’s digital phone number. When a customer/member receives a text, the message originates from this number.

Message Thread

The list of sent and received text messages display in this chat box. User, Date, and Time are displayed for each message.

Note: The first outgoing message in this box sends and Opt Out message to the customer/member. The system adds the following text to the end of the message, “Reply STOP to opt out. Msg & Data rates may apply.” If the customer/member replies, “Stop,” the Consent field for the customer/member phone number is updated to Y (Valid, Voice Only) on the Add New/Edit Existing Customer/Member window. Any previous messages can only be viewed from the Contact History window.

When the customer/member texts, “Start,” the Consent field for the customer/member phone number is updated to B (SMS Text & Voice). 

Send Message

This text box defines the next text that will be sent from your institution’s employee to the customer/member number as a text message. When you click Send, the text in this box is sent and cannot be cancelled. 

Action

Send

This button texts the message in the Send Message box. This action cannot be cancelled. 

Spell Check

This button performs spell check on the text in the Send Message box.
