Employee Long Code Mapping Window

Window Path: System Administration > Institution button on the ribbon > Interfaces button > SMS Service option > Edit button > Lng Cd Map button  > New/Edit button > Close button

This window assigns employees or employee classes to a long code for the Text Messaging interface feature.

Long Code

This field displays the long code generated on the Long Code dialog.

Description

This field displays the description defined for this long code.

Table

Employee ID

This column displays the unique number that identifies an employee.

Employee Name

This column displays the full name of the employee.

Status

This column displays the status of the employee record.

Action

Add

This button opens the Add Employees window to give permissions to an employee to send text messages from a long code.

Remove

This button removes the highlighted employee’s ability to send text messages from a long code.
