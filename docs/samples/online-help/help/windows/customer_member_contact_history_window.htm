Customer/Member Contact History Window

Window Path: Variable "CMM" is not defined > Any Variable "custmbr" is not defined window > Contact History button on the ribbon

This window lists Variable "custmbr" is not defined contact records. This information can be used to determine dormant accounts based on settings in Customer Controls. If your financial institution licenses Sales & Service, the system can be configured to automatically add contact records for certain servicing tasks.

Contact History Tab

FilterFilter

Contact Date

This check box enables you to filter your search by date or date range. The To and From fields enable when this check box is selected.

From

This field defines the start date for your search. This field is enabled only when the Create Date check box is selected.

To

This field defines the end date for your search. This field is enabled only when the Create Date check box is selected.

Employee

This check box enables you to filter your search by the employee from which contact history records were generated. The list adjacent to this field enables when this check box is selected.

Account

This check box enables you to filter your search by account. The list adjacent to this field enables when this check box is selected.

Contact Type

This check box lets you filter your search by contact type. The list adjacent to this field enables when this check box is selected.

ID

This column displays the unique numerical identifier of the contact history record.

Contact Dt

This column displays the date that your financial institution was in contact with the customer/member.

Time

This column displays the time at which your financial institution was in contact with the customer/member.

Contact Type

This column displays the type of contact record.

Description

This column lists information about the contact.

Ref/Req Status

This column displays the status of the referral (Pending, Sold, Declined) or request (Pending, In Process, Completed, or Declined).

Created By

This column lists the employee who created the contact record.

Account

This column displays the account related to the contact record. This may be masked, depending on the whether the account is an external account that has account type configured for masking.
