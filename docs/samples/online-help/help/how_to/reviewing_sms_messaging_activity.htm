Reviewing SMS Messaging Activity

This procedure displays previous texts between customers/members and employees.

In Customer/Member Management, search for and select a customer/member to display the Relationship Management window.

Click the Contact History button on the ribbon to open the Customer/Member Contact History window.

Select the Contact Type filter and choose Text Message to show only SMS messaging activity.

Description indicates whether the text was sent or received. 

Sent Text

Received Text

Highlight a message in the table and click Details to open the Text Messaging window. The window opens with the selected text message in focus, so you can see the relevant text, highlighted, and where the text occurred in the message thread.
