Sending and Receiving Text Messages

The Text Message Window is the central location where you can send, receive, and review the history of text message conversations with a customer/member.

Accessing the Text Message Window

Open Customer/Member Management and select the Teller or Customer/Member Management tab.

On Teller tab, click the Post button on the ribbon to find and select a customer/member on the Relationship Management window. 

On the Customer/Member Management tab, click the Search button on the ribbon to find and select a customer/member on the Relationship Management window.

Click the Contact button on the ribbon, hover over Text Customer/Member, and select an eligible phone number.

Note: This window can also be displayed from the Relationship Management window when the customer/member phone number link is clicked. Links are only displayed for mobile phone numbers with Consent set to B, G, H, S, U, V, or <none>.

The Text Message window displays.

Sending and Receiving Messages

IMPORTANT! The first outgoing message in this box sends and Opt Out message to the customer/member. The system adds the following text to the end of the message, “Reply STOP to opt out. Msg & Data rates may apply.” 

If the customer/member replies, “Stop,” the Consent field for the customer/member phone number is updated to Y (Valid, Voice Only) on the Add New/Edit Existing Customer/Member window. Any previous messages can only be viewed from the Contact History window.

When the customer/member texts, “Start,” the Consent field for the customer/member phone number is updated to B (SMS Text & Voice). 

Review the window information to ensure you are texting from the correct institution number. You may want to review the message thread for previous conversations.

Institution SMS Number displays the Long Code defined in System Administration that is assigned to the employee. Multiple employees may be assigned to the same long code. 

The list of sent and received texts display in the chat box. User, Date, and Time are displayed for each message.

The scroll bar displays previously sent and received text messages. 

Note: Because multiple employees can share the same long code, the message thread displays all conversations from the Institution SMS Number (Long Code), regardless of the employee currently viewing the message thread.

Enter a message in the text box at the bottom of the Text Message window and click Send.

IMPORTANT! Sent message cannot be cancelled. 

The chat box updates the message thread with your sent message. This window provides live updates, so you can stay on the window to see and send responses from a customer/member in real time.

Note: Clicking on a message changes the highlight color of the text message.
