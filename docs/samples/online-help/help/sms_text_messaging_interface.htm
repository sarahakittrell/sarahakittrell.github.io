SMS Text Messaging Interface

Note: Text Messaging integration is a separately licensed enhancement that requires setup by Professional Services. Please contact your Account Executive for more information.

Text messaging continues to be a preferred method of communication for many customers/members. Anecdotally, several financial institution officers have told us that their employees are using personal cell phones to text customers/members and expressed privacy and security concerns around that activity. 

Texting performed outside of the financial institution’s core provides no way to monitor that activity to ensure the messages are within regulatory guidelines and the financial institution’s policies. There is also no retention available and, if the financial institution employee leaves the financial institution, there is no means to remove that information from the employee’s personal device. One alternative is to purchase a financial institution-owned device with Mobile Device Management, but that can be cost prohibitive.

The SMS Messaging interface integrates text messaging into Customer/Member Management through a digital text messaging service. Service ID 514 (SMS Service) integrates the core with a cloud communications platform that issues digital phone numbers for text messaging. Once enabled, your institution can register digital phone numbers and assign them to employees, allowing text messages to be sent and received directly from the Relationship Management windows in Customer/Member Management. 

Setting Up Text Messaging Controls

Once the text messaging interface is enabled, Long Codes must be created for your employees in the Long Code Configuration window. After registering a long code, the Employee Long Code Mapping window opens to display a list of the employees allowed to use that phone number to send and receive text messages in Customer/Member Management.

Employees not listed on the Employee Long Code Mapping window can be added by clicking the Add button to display the Add Employees window. Highlight one or more employees and click Select to assign these employees to the long code. The Employee Long Code Mapping window updates to display the employees mapped to the long code.

Once employees are mapped to a long code, window security for the Text Messaging window in Customer/Member Management must be provided to security classes and employees.

Go to the Text Messaging Interface User Guide for complete setup procedures.
